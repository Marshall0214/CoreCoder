# 验收材料范围

本目录保存工程回归、Docker 与 CLI/API 离线演示的验收证据，模型调用为零。

demo/ 来自仓库随附的合成任务。示例仓库、全零 commit、Issue URL 只作为本地夹具身份，未抓取 GitHub、未引用真实缺陷或声称模型修复成功。公开检查和修复动作均为项目编写的脚本。

full-junit.xml 的条件跳过与 Docker 单独验收分开记录；Docker 验收确实创建固定镜像容器，不是模拟容器结果。源代码和合成夹具遵循仓库根目录的 [MIT 许可证](../../LICENSE)。

运行状态可为 ready_for_review，同时 accepted=false，表示待人工审查而非独立评分成功。文件哈希仅用于一致性检查，不是第三方认证。
