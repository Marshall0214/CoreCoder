# 符号级局部上下文：离线原型 v1

## 本次实际完成

新增 `evals/symbol_context.py`，将关键词命中展开为函数、方法或类的局部代码证据，并静态追踪本地符号依赖。新增局部补丁防护接口。尚未接入真实 Agent 或模型补丁生成，本次模型调用为 0。

动机：现有有限 pipeline 只接收完整文件，Click 大文件会超出正文预算而被跳过。局部策略应能提供少量相关源码，同时明确哪些上下文没有给模型看到。

## 策略与约束

1. 使用现有固定行 BM25 索引对公开问题描述检索；从排名中的 Python 命中选取至多 5 个不同符号种子。本策略仅选择代码，Markdown 不进入最终上下文。
2. 在命中窗口中选取关键词重合最多的行，用 AST 找到包围该行的最小函数、方法或类。装得下时返回完整符号，包含装饰器和 async 定义。
3. 符号过大时只返回命中的完整行窗口，标记 complete_symbol false，并记录原始 symbol_range；不能将局部片段当作完整函数或类。无法解析的源码明确标为 syntax-error-window。
4. 解析本地 import/from 别名、相对导入、模块属性引用、同文件符号及 self/cls 方法引用；扩展深度默认 1，范围仅为允许源码。全过程只读与 AST 解析，不导入或执行仓库代码。
5. 总正文预算默认 6,000 字符，片段数不超过 20；去除重复和重叠范围，预算放不下时记录丢弃原因，不截断半行。元数据及模型输出预留需要后续工作流另行计算。

每个片段携带相对路径、限定符号名、行号、全文件 SHA-256、原始符号范围、完整性、解析状态、选择原因及深度。保留原文件 CRLF 和缩进，索引后源文件变化直接拒绝。Trace 记录种子、依赖边与丢弃项。

静态引用是启发式依赖，不是完整 Python 调用图；可能包含类型注解引用，也不能可靠处理动态属性、变量遮蔽或运行时导入行为。不解析为 AST 的片段不做依赖展开。

`apply_symbol_patch` 先检查全部 old 文本都出现在给定局部片段中，再复用既有 JSON 补丁的允许文件、全文件版本、唯一匹配与写入前校验。不能仅因为某文件获准修改，就改动未提供的部分；未展示的文本或过期版本导致整组补丁在写入前被拒绝。该接口已离线测试，尚未接入 live 模型流程。
