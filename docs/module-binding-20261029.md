- 在现有 `read_symbol` 中增加同一允许文件内的赋值和导入声明读取。支持类型注解、链式/解包赋值、普通/相对导入及别名。
- 返回原文、行范围、文件字节哈希、分页信息及 `kind`；导入另带 `import_source`，明确 `followed=false`。仅类型注解而没有赋值时明确 `value_present=false`。
- 所有内容静态解析，不执行赋值表达式、不导入模块、不跟随来源文件；函数局部和类内赋值不当作模块绑定。通配导入和动态绑定不解析。
- 同名多次声明（包括条件或异常分支）返回歧义，不推断运行时分支；保留原有允许路径、唯一锚点、版本和暂存校验。
- 同步工具说明，避免把导入声明误当成被导入函数的实现。
