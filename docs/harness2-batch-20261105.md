## 读取进度与结果

- `report.json`：公开准入数量、当前组别/任务、每项结果、两组汇总与新增/丢失成功任务。
- `protocol.json`：固定数据、代码哈希、分组规则、模型及执行边界。运行期间不修改这些代码或输入。
- `launcher.json`：后台启动器是否在等待准入、正在运行、已结束或失败。
- `batch.stdout.log` / `batch.stderr.log`：模型批次总日志；各任务 `worker.log`、`result.json`、反馈目录保留明细。
- 每项生成 Trace 继续发送至本地 Langfuse；批次最终对照与服务器回读在完成后整理，不以 SDK 提交状态冒充服务器已确认。
