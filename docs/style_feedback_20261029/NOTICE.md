# 来源与范围

本包记录 Click #3887 第二轮开发试验：扩充公开保持性检查，再从原始代码启动一次本地 Qwen3.5 27B 无思考任务。不是未见任务、独立评分或上游认可的修复结果。

`execution/` 保存计划、准入与前后完整性；`prepared/` 只保存准备元数据和公开检查，源码仍来自原固定快照，未在此重复打包。

`live/` 是实际调用的消息、回答、工具结果和日志；模型没有提交编辑，净补丁为空。源码摘录来自 pallets/click 固定 commit `934813e4d421071a1b3db3973c02fe2721359a6e`，保留 [BSD-3-Clause 许可证](LICENSE-click.txt)。原始 Issue 来源及时间保存在 `prepared/issue.json` 和派生准入记录中，没有重新抓取 GitHub。

`public/` 与 `configuration.json` 是本轮使用的版本化公开开发检查副本：原目标与三项正常行为加六项事后审查诊断。这些用例对模型可见，不能当作隐藏验收。原检查与原候选记录保持不变。

`validation/` 记录可信检查定义的一致性、发现数量和既有执行器相关回归测试。六组容器执行中包含预期的目标失败和旧候选四项回归，不能把这些失败计作环境故障。

未手工修正候选，未新增付费调用；文件哈希用于一致性核对，不是第三方认证。
