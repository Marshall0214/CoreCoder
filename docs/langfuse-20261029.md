## 部署阻塞与已有进展

Docker 数据目录已核实位于 D 盘。官方 Docker 入口返回网络 EOF；既有镜像源还返回过大小不符的 layer，Docker 已拒绝，未降低完整性校验。

根据用户建议测试 localhost:7890：端口可连接，通过它成功下载并核对官方镜像传输工具 SHA-256，Redis 与 MinIO 镜像成功导入。其余四个镜像遇到 EOF、TLS 超时或传输不完整；最后一轮设置 180 秒上限后停止。并行传输曾发生共享缓存文件占用，已为该重试分离缓存；后续仍因传输未完成而停止。只使用官方仓库，未运行不完整镜像。

未执行 Compose up，未修改 Docker 全局代理或重启 Docker，未占用 8001。现阶段没有可用仪表盘，也没有经服务器回读确认的 Trace。所有新增依赖、镜像下载、缓存、凭据和证据保存在 D 盘。
