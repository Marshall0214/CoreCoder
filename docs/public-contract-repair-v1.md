# 公开 flag 契约验证与反馈修正 v1

## 解决的问题

旧公开测试只断言结果不等于激活值，因此返回 None 或原始环境变量字符串的错误补丁也会通过，反馈修正被跳过。新增独立版本的公开契约检查，精确判断未激活值；旧公开测试、冻结保持性检查及独立评分文件保持不变。

公开契约显式声明 type=str、default=False、一个字符串 flag_value，并要求未激活输入得到声明中的 False 经字符串转换后的结果。覆盖假值、不匹配字符串、精确匹配、真值、布尔空白、命令行优先及普通整数选项转换。预期来自公开需求与测试自己的声明，不以独立评分输出为运行时 oracle。作者已接触历史失败诊断，本轮是已知失败开发，不能声称盲测。

## 实现

- flag_contract_v1.py 保存不可覆盖的公开检查版本。
- public_contract_feedback_v1.py 将新检查与原公开/冻结检查共同用于保留、反馈及回滚。新检查失败且可执行时触发最多一次修正，反馈只包含公开代码与实际失败日志。
- public_contract_repair_v1.py 在模型运行前验证：原始源码复现失败、正常行为通过、参考修复全部通过。参考仅用于离线认证，不进入模型请求。
- 初始检索沿用 caller-fallback-context-v1，仍仅提供五个原文片段、最多六千字符；新契约不改变初始提示，只改变候选的验证与反馈。

## 边界

当前是手写公开行为契约，尚未自动生成任意 Issue 的充分测试；也未穷举 flag 的所有组合及整个上游测试集。不能保证公开契约通过就一定正确，独立评分仍保留最终判定作用。代码仅为可选实验，未替换默认服务流程。
