# 来源与范围

本目录保存对已生成 Click #3887 候选补丁的事后兼容性诊断。新增用例由本项目编写，不能当作上游测试、未见测试或新的独立评分。

`upstream/` 是 pallets/click 固定 commit
`934813e4d421071a1b3db3973c02fe2721359a6e`（8.1.8）的源码与测试节选，行号见节选文件首行；保留 [BSD-3-Clause 许可证](LICENSE-click.txt)。它们用于说明诊断依据，未运行上游完整 pytest 套件。

`execution/` 保存同一 Docker 镜像下原始版本与冻结候选的六组检查及原始日志；诊断副本单独挂载，不改原四项公开检查。日志中有预期的缺陷及回归断言失败。

`validation/` 保存可信诊断解析器和已有历史观察精简测试的 JUnit。没有新模型推理、API 请求或人工修正候选；输入内容与容器清理由 postflight 记录核对。

文件哈希用于一致性检查，不是第三方认证。上一轮模型记录仍在原证据包，未因本次回归发现而改写。
