## 可以支持与不能支持的结论

关键词证据进入全部 15 次模型上下文，并出现两份满足测试的候选补丁及一次端到端成功。它解决了“入口未提供契约”的问题，但不保证模型理解全部契约、完成所有修复或在预算内收尾。

28/30 次由累计预算预检终止。实际用量未达到 30,000 也可能停止，因为下一次估算输入与预留输出必须放进剩余预算。此条件对实验结果有强约束；不能把所有失败简单归因为检索失败或模型能力不足。

只有 5 个独立人工任务，3 次重复不能当作 15 个独立任务。0/15 与 1/15 是探索性原始结果，不足以证明统计显著提升或真实仓库泛化。交替批次未完全控制模型加载、缓存及任务顺序，耗时仅描述本次运行。
