# 三项失败任务的定向上下文改进

## 范围

仅运行 boltons-remap-set、more-range-membership、click-prompt-suffix，不重跑原已通过任务，不重跑完整五十项。三项均来自已完成 DeepSeek 高思考实验的失败任务；包含已观察的历史保留集任务，本轮属于已知失败调试，不是盲测或新全量成绩。

保持 DeepSeek Flash 高思考、最多两次补丁生成、60,000 累计 Token、32,768 单次生成上限、65,536 上下文预算、原公开检查和独立评分。变化仅为代码上下文选择及反馈时重新选择当前源码。历史 43/50 保留。

## 实现

- 描述中精确匹配且可唯一解析的顶层函数、指定类方法优先。普通词不自动提升其他类的同名方法，避免再次引入无关实现。
- 对指定类按描述涉及的成员判断、长度、迭代补充 Python 协议方法，并沿 AST 直接引用展开一层辅助方法。
- 最多五个片段、合计六千字符。长函数的文档说明不能挤掉实现：对长文档函数提供连续的实现正文，并附签名、原始函数范围和部分片段标记。不会将不相邻源码拼成可编辑片段；超预算仍会记录遗漏。
- 反馈阶段基于当前候选源码重新生成上下文与文件 hash，保留唯一原文锚点、公开检查和原冻结检查、失败回滚。独立评分结果不反馈给模型。

根因核对：原 remap 函数共 7,867 字符，被旧六千字符完整函数打包器整个跳过；新正文片段为 2,655 字符，另包含 default_enter/default_visit/default_exit。范围任务现包含 __contains__、_len、__len__、__iter__、index；提示任务现同时包含 prompt 和 confirm。
